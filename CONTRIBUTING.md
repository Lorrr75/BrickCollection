# Contributing / Contribuire

**[English](#english) | [Italiano](#italiano)**

---

## English

This is currently a personal, actively-developed project. That said:

- **Bug reports**: open an issue with clear reproduction steps, expected vs. actual behavior, and your environment (Windows version, Visual Studio version, Android API level)
- **Feature suggestions**: open an issue describing the use case — no guarantee of implementation, but ideas are welcome
- **Pull requests**: please open an issue first to discuss any non-trivial change before submitting a PR

### Development Style

This project follows an incremental development approach: small, testable changes, one at a time. Please keep PRs small and focused for the same reason.

By contributing, you agree that your contributions will be licensed under the project's EUPL-1.2 license.

## Italiano

Questo è attualmente un progetto personale, in sviluppo attivo. Detto questo:

- **Segnalazioni di bug**: apri una issue con passi di riproduzione chiari, comportamento atteso vs. reale, e il tuo ambiente (versione Windows, versione Visual Studio, livello API Android)
- **Suggerimenti**: apri una issue descrivendo il caso d'uso — nessuna garanzia di implementazione, ma le idee sono benvenute
- **Pull request**: apri prima una issue per discutere qualsiasi modifica non banale prima di inviare una PR

### Stile di Sviluppo

Questo progetto segue un approccio di sviluppo incrementale: modifiche piccole e testabili, una alla volta. Per lo stesso motivo, ti chiedo di mantenere le PR piccole e mirate.

### Nota sulla licenza

Contribuendo, accetti che i tuoi contributi saranno rilasciati sotto la licenza EUPL-1.2 del progetto.
